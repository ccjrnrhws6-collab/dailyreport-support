施工日報表 Daily Report

為施工及機電現場人員設計的施工日報表 App：快速建立日報、拍照與附件、匯出 PDF；Pro 訂閱提供雲端同步、雲端草稿、工令彙整與 CSV 匯出。
A daily construction report app for site staff.

常見問題 FAQ

如何登入？ 在 App 內以 Email 註冊/登入；忘記密碼可使用「忘記密碼」重設。

Pro 訂閱與恢復購買 Pro 僅能於 App 內透過 Apple 內購（月訂／年訂）購買。換機或重新安裝後，請按「恢復購買」。

如何取消訂閱？ iPhone「設定」→ 點選你的 Apple ID →「訂閱」→ 選擇「施工日報表」→ 取消訂閱。
Cancel via Settings › Apple ID › Subscriptions.

匯出 PDF / CSV 日報預覽頁可匯出 PDF；CSV 匯出（Pro）在「編輯工程」中的「匯出 CSV」。

刪除帳號或資料 請寄信至 k44514@gmail.com，註明登入 Email，我們將協助刪除帳號與雲端資料。
